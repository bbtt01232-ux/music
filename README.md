# CKRPRO MUSIC — Vercel

## Deploy
1. Push to GitHub
2. Vercel → Import project
3. Framework: Other
4. Deploy

## Local / Termux
```bash
pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000

## Features
- Real WhatsApp + YouTube icons
- Clean UI (no glow / no borders)
- Background play (lock screen + recent apps)
- Media Session controls
